# August 2026

## 2026-08-11

- Graphs can switch between light and dark theme presets at construction or runtime, and the canvas background can be a solid color, transparent for a host CSS pattern, or a tiled image/canvas pattern.
- Overlay labels support a `focus` policy (selected, hovered, and neighbors) so dense graphs stay readable; pointer hover updates node highlight automatically.
- Overlay toolbars can auto-anchor to the selected or hovered node when `renderToolbar` is set.

## 2026-08-10

- Pointer picking can resolve edges as well as nodes (`pickHit`), and selected edges highlight with a theme color without clearing node selection.
- Overlay labels can follow a viewport budget (`autoLabels`) so only the most important on-screen titles appear within `maxLabels`, without hosts guessing `setLabels()` every frame.

## 2026-08-08

- Docs gained a fullscreen Explorer at `/explore/` with grid, circle, force, and live force layouts plus appearance controls. `/benchmark/` stays the Prove protocol; its Explorer tab links to the fullscreen surface.
- Edges can follow straight, quadratic, or cubic paths. Supply control points or let graphraum derive them; overview zoom still collapses curves to a single straight segment.
- Fixed a WebGL shader validate failure where node fill color was declared twice (`instanceColor` redefinition).
- The docs `/benchmark/` page hosts the timed Prove protocol and local history; live shape and edge exploration moved to the fullscreen Explorer.
- Nodes gained four shapes—hexagon, triangle, pill, and rounded—alongside the existing circle, square, and diamond. Every shape can now draw an outer stroke and set width and height independently instead of one uniform size.
- Edges support width, opacity, dash styles, and triangle direction markers, with overview zoom dropping markers first.
